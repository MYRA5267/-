## Что работает частично — и почему

**Threads, Instagram, TikTok — экспорт, а не автопостинг.**
Так и написано в ТЗ (раздел 10): полный Direct Post в TikTok включается
после одобрения `video.publish` и аудита приложения, Instagram зависит от
App Review, Threads — от production-доступа Meta. Модули площадок уже есть
и реализуют общий интерфейс `Connector`; когда доступы выданы, меняется
один файл на площадку, остальная система не трогается.

**Глаз PULSE — векторный, не GLB.**
Все семь состояний на месте и берутся из реальной очереди, а не
проигрываются случайно. Версия на React Three Fiber с Draco-сжатием —
следующий шаг: интерфейс к ней уже готов, состояние приходит одним
значением в `<Eye state={...} />`.

**Голос и медиа в банке идей.**
Сейчас вход текстом. Приём голосовых и файлов через бота — следующий шаг,
таблица `assets` и путь публикации медиа уже есть.

**Автосбор метрик.**
Telegram Bot API не отдаёт просмотры постов канала, поэтому метрики
вводятся руками — и на экране видно, что источник ручной. Автосбор
появится вместе с insights Threads и Instagram.

**Без ключа модели продукт работает.**
`ANTHROPIC_API_KEY` не задан — версии собираются как раскладка идеи по
формату площадки, и приложение прямо говорит: «собрано без модели».
Притворяться моделью нельзя.

## Ещё не начато

Видеоредактор, генерация длинных видео, покупка рекламы, биллинг,
white-label, YouTube Shorts / VK / LinkedIn / Pinterest / X — всё это
за границей первого релиза по разделу 4 ТЗ.

## Как проверить

```bash
npm test                  # чистая логика: статусы, идемпотентность, humanizer, аналитика
npm run pulse:rls-check   # изоляция арендаторов и роли — на живой базе
npm run build             # сборка
```
